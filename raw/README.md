# raw/

Original source material. Axis treats everything in this tree as **evidence** —
screenshots, emails, DMs, invoices, contracts, analytics exports, receipts,
creative references, notes, proposals.

Subfolders:

- `client-assets/` — brand books, logos, decks, photography, reference reels
- `proposals/` — proposals sent, scopes, SOWs
- `invoices/` — issued invoices, paid stubs, PDFs from clients
- `expenses/` — vendor bills, contractor invoices
- `analytics/` — exported CSVs / screenshots from IG, TikTok, YouTube, GA
- `shoot-notes/` — production notes, call sheets, BTS logs
- `receipts/` — anything that lands in a tax category
- `misc/` — everything else; Axis triages

Bulk contents are gitignored. The folder structure is preserved.

Axis compiles this into structured knowledge under `wiki/`.
