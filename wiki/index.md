# ATLY Axis Wiki

The compiled brain of ATLY Studios. Everything here is durable, structured
knowledge — distilled from `raw/`, conversations with Axis, and operational
events in the database.

## Map

- [_status.md](./_status.md) — what is happening at ATLY *right now*
- `clients/` — one file per client: brand, contacts, history, posture
- `projects/` — one file per project: brief, deliverables, risks, learnings
- `campaigns/` — concepts, hooks, hero direction, results
- `finance/` — revenue patterns, runway, tax notes, vendor terms
- `analytics/` — what worked, what didn't, by client + format
- `lessons/` — durable lessons learned. Never delete.
- `brand/` — ATLY's own positioning, voice, visual identity
- `journal/` — dated entries when Tristian tells Axis something worth remembering

## Conventions

- Markdown only. Lowercase-kebab filenames.
- Top of file: a one-line summary.
- Use front-matter sparingly. Prefer headings + lists.
- Axis is allowed (and expected) to edit this tree.
